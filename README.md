# Finger Gun Space Shooter

A real-time webcam-controlled shooting game using Python, OpenCV and MediaPipe.

## Features

- Real-time hand tracking
- Finger gesture controls
- Moving targets
- Shooting system
- Ammo and reload
- Score and combo
- Accuracy tracking
- Player name
- Leaderboard

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- Git
- GitHub
